# Typed, installable uv project

This example is an **independent** `uv` project. Run commands from this directory, not the parent `python/` directory:

```sh
uv sync
uv run sample-label "  Hello   World  "
uv run pytest
uv run ty check
uv build
```

The CLI prints `hello-world`. The package under `src/sample_tools/` is installed in the environment because `pyproject.toml` declares a build system. Import tests exercise the public package rather than relying on arbitrary `PYTHONPATH` edits.

Commit the generated `uv.lock` when adopting this pattern for a deployable application. Once committed, CI should use `uv sync --locked` and `uv run --locked pytest`. The example leaves the lockfile to be generated by its first `uv sync`.
